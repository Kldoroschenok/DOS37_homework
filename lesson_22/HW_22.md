## Задание 1: php:8.2-apache + bind mount
Запуск:
```
docker run -d --name php-web-1 -p 8000:80 \
  -v ~/docker_files/index.php:/var/www/html/index.php \
  php:8.2-apache
```
Проверка: `curl -I 127.0.0.1:8000`
```
HTTP/1.1 200 OK
Server: Apache/2.4.69 (Debian)
X-Powered-By: PHP/8.2.35
Content-Type: text/html; charset=UTF-8
```
## Задание 2: python:3.11 + hello.py
Запуск:
```
docker run -it --name sayhello-1 \
  -v ~/docker_files/hello.py:/app/hello.py \
  python:3.11 bash
```

Проверка: `python /app/hello.py`
```
Hello, root you inside in 921f21668a86
```
## Задание 3: php:latest + info.php
Запуск: 
```

```
